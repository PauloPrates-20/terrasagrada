Site desenvolvido para uso no servidor de rpg de mesa **Terra Sagrada** do **Discord**.

Visite [Terra Sagrada](https://terrasagrada.net.br) para conferir.

## Funcionalidades

- Integração com discord para automação de compras no servidor
- Listas de itens consumíveis, mágicos e mundanos para consulta
- Ferramentas de auxílio na criação de personagens
- Ferramentas que auxiliam na utilização das mecânicas internas do servidor
